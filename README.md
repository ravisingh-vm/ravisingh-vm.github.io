# Ravi Singh's DevOps Fieldbook

Personal DevOps knowledge hub published with GitHub Pages at
[ravisingh-vm.github.io](https://ravisingh-vm.github.io/).

The site currently includes:

- application-specific delivery strategies
- a phased DevSecOps implementation plan
- searchable and filterable personal knowledge notes

## Editing

The site is a dependency-free static page. Update `index.html`, open it in a
browser to preview the change, and push the change to `main` for GitHub Pages
to publish it.
